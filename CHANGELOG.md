# Changelog

## 1.0.3 (2026-11-11)

First release to organisations.

- Six tools: `whoami`, `search_datasets`, `list_datasets`, `describe_dataset`, `query_dataset`, `urql_guide`.
- Sign in with your uSmart account; the agent sees only what you can see on usmart.ai. Read-only.
- When a user belongs to more than five organisations, the agent asks which to look at first.

Earlier versions (1.0.0 to 1.0.2) were internal.
